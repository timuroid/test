# Дизайн-система по PDF-образцу

Правила извлечены из 21 страницы `assets/reference.pdf` и сверены с совпадающим HTML/CSS исходного курса. Это описание данного оформления, а не универсальные правила всех университетских презентаций. Контактный лист показывает все композиции; исходный PDF остаётся визуальным эталоном. Старые тема, персонажи, команды и учебные примеры не входят в требования к новым презентациям.

## Холст и сетка

Все размеры ниже — CSS px на холсте 1280 × 720, 16:9. В PDF образца координаты и кегли умножены на 0,75. Для другого разрешения масштабируй весь холст равномерно.

| Элемент | Значение |
| --- | --- |
| Основные поля | 70 слева/справа, 50 сверху |
| Заголовок | x=70, y=50, ширина до 1110 |
| Область содержания | x=70, y≈168, w=1140, h≈470 |
| Низ основной композиции | до y≈638; оставь воздух перед номером |
| Номер слайда | справа, right=70, bottom=28; `01 / NN` |
| Две колонки | промежуток 35–70, одинаковая базовая линия |
| Три этапа | равные смысловые блоки и узкие промежутки под стрелки |
| Панели | внутренние поля 24–38; радиусы 16–28 |

Большое белое поле между заголовком и схемой намеренно. Композиция занимает центральную часть, а не всю высоту слайда. Небольшой текстовый блок не растягивай ради заполнения. У отдельных схем образца начало y=160–200; это допустимая адаптация, а не новая сетка на каждом слайде.

## Цветовые токены

| Токен | Цвет | Применение |
| --- | --- | --- |
| `blue` | `#176DEA` | обложка, акценты, стрелки, номера шагов |
| `ink` | `#434343` | заголовки и основной текст |
| `muted` | `#737B88` | пояснения, подписи, номер страницы |
| `paper` | `#FFFFFF` | содержательные слайды |
| `light` | `#EDF4FF` | подсветка блока, круг номера, плашка итога |
| `line` | `#DBE5F2` | разделители, таблицы, нейтральные границы |
| `outline` | `#9EBFF1` | контур облака/устройства/модельной схемы |
| `soft-blue` | `#F5F8FD` | вторичная поверхность, экран, файл |
| `green` / `green-bg` | `#176953` / `#EAF7F2` | добавление, успешная проверка |
| `red` / `red-bg` | `#9C3B31` / `#FFF0ED` | удаление, ошибка в сравнении |

По умолчанию доминируют белый, серый и синий. Зеленый/красный появляются только при соответствующем смысле. На сложной многокомпонентной схеме допустимы приглушённые вторичные оттенки, как на странице 2. Не вводи декоративный радужный набор. Тёмный `#14233B` вокруг HTML-холста — фон просмотрщика, не фон содержательных слайдов.

## Типографика

| Роль | Размер / начертание | Примечание |
| --- | --- | --- |
| Обложка | 69 px / 700 | line-height 1,13; tracking −2 px; до 1000 px ширины |
| Заголовок слайда | 46 px / 700 | line-height 1,13; tracking −1,2 px |
| Заголовок панели | 28–38 px / 700 | чаще 31–32 px |
| Основной текст | 24–28 px / 400 | line-height 1,35–1,5 |
| Пояснение | 20–23 px / 400 | краткая подпись, не основной рассказ |
| Надпись над блоком | 15–17 px / 400 | muted; иногда uppercase с tracking 0,4–1 px |
| Нумерация | 15 px / 400 | muted; белый с пониженной непрозрачностью на обложке |
| Код | 22–24 px / monospace | интерлиньяж 1,3–1,5; подсветка отдельных значимых строк |

Основная гарнитура — Inter Regular и Bold, локально вложенные в skill. В PDF имя `InterCourse-*` — внутреннее имя этих файлов. Courier/Times встречаются внутри учебного Markdown-кода: это особенности печати конкретного примера, а не обязательная пара шрифтов системы. Используй один корректно отображающий кириллицу monospace для кода. Не делай весь основной текст мельче ради вместимости.

## Обложка и водяной знак

Обложка полностью синяя. Белый крупный заголовок начинается около x=75, y=171. Под ним горизонтальная белая линия x=75, y≈374, w=700, 2 px; короткая формула темы около y=407, дата/сезон около y=472. Координаты относятся к образцу; длинную новую тему можно перенести на две строки с проверкой свободного места до линии.

На содержательном слайде герб находится справа внизу: right=27, bottom=26, коробка 228 × 270, `object-fit:contain`, opacity 0,4 для `crest-blue-watermark.png`. У PNG максимум alpha=14/255: итоговый знак очень бледный. На обложке: right=35, bottom=30, 290 × 345, opacity 0,8 для `crest-white-watermark.png`, у которого максимум alpha=59/255. Не заменяй эти файлы более насыщенными `crest-blue.png`/`crest-white.png`, сохранив те же opacity: знак получится значительно темнее. Знак лежит под содержанием, номер — над ним.

Карточка — смысловая поверхность, а не обязательная упаковка каждого предложения. Сохраняй разнообразие: открытые схемы, строки, тонкие разделители, номерные шаги. Не превращай всю презентацию в одинаковые сетки плиток.

## Иллюстрации, схемы и текст

Используй простые редактируемые контурные пиктограммы: человек, агент, документ, папка, ноутбук, облако, история, ссылка, галочка. Обычно синий stroke 1,5–2,5 px, без объёма, градиентов и фотографического фона. Для HTML подходят inline SVG с `currentColor`. Стрелки тонкие, однонаправленные и подписанные действием; цвет не заменяет подпись. Реальные логотипы добавляй только если они нужны теме, не наследуй GitHub автоматически.

На слайде короткий заголовок, конкретная схема и несколько подписей. Подробное объяснение, оговорки и источники переноси в заметки, если они не необходимы для правильного понимания схемы. Не ставь мелкий абзац вместо визуальной модели. Тени допустимы едва заметные, только чтобы отделить объект; в основном система плоская.

## Проверка верности стилю

Сравни с контактным листом: белая основа, синий как единственный ведущий акцент, Inter, верхний левый заголовок, свободное пространство, мягкие поверхности, тонкие контуры, нижняя правая нумерация. Не добавляй декоративные градиенты, фотографии фоном, огромные номера, плотный верхний баннер или новый постоянный подзаголовок на каждый слайд. Запрос пользователя на другие элементы имеет приоритет.
