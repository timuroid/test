# Academic Blue Slides

Навык Codex для создания презентаций по бело-синей академической дизайн-системе из предоставленного PDF: Inter, синий `#176DEA`, тонкие контурные схемы и полупрозрачный герб.

## Установка и использование

Попросите Codex: «Установи навык из https://github.com/timuroid/test/tree/main/academic-blue-slides».

После установки вызовите:

```text
Используй $academic-blue-slides и создай презентацию на тему …
Аудитория: …; цель: …; формат: HTML и PDF.
```

Навык хранится в [`academic-blue-slides/`](academic-blue-slides/SKILL.md). Внутри — подробная дизайн-система, исходный PDF, контактный лист, шрифты Inter с лицензией OFL, водяные знаки и автономный HTML-шаблон с пятью композициями.

Для создания стартового файла из локальной копии репозитория:

```bash
python3 academic-blue-slides/scripts/make_deck.py --output /tmp/academic-blue-presentation.html
```

Генератор требует Python 3.9+, работает без сети и встраивает ресурсы в HTML. Существующие файлы не перезаписывает. Для PDF откройте результат в Chromium и сохраните через печать с фоном и без колонтитулов браузера. Формат PPTX создаётся доступным редактором презентаций по тем же правилам дизайна; генератор создаёт HTML.

Это визуальный стиль по образцу, не официальный брендбук университета. Символика не означает официальное авторство. При замене учреждения или отказе от символики герб можно убрать согласно инструкции навыка. Условия использования шрифтов — в [`OFL.txt`](academic-blue-slides/assets/fonts/OFL.txt).
